# さいわいさん TEST v12 | 0時 郵政局 — 小節指定プレーヤー

Firebaseなし・Google Driveからの音声取得なしの、UI検証用PWAです。

## 操作方法

1. GitHub Pagesで `saiwaisan-test` の中の全ファイルを公開。
2. 曲リストから **「0時　郵政局」** の詳細を開く。
3. 追記メモ**1列目「全体・レビュー」**の見出しにある **「▶ 小節で再生」** を押す。
4. ポップアップで再生/停止、時間シークバー、小節シークバー、小節番号の手入力、±1/±4小節移動を操作。
5. **「ここから再生」** を押すと指定小節に移動し、自動再生。初期設定では「0.5秒前」から開始。チェックを外すと小節の先頭から開始します。
6. 下部は**「構成」「全体・レビュー」**の2カラム表。構成名を押すとMIDIの該当マーカーの小節へ移動して再生します。
7. 再生小節に応じて構成行をハイライト。「構成に追従」を外せば表の自動スクロールを止められます。

## MIDI解析結果

- BPM: **192**（曲中でテンポ変更なし）
- 第1小節開始: **0.000秒**（ユーザー指定により、MP3先頭と一致）
- **1〜192小節: 4/4拍子**
- **193小節: 2/4拍子**（240.000〜240.625秒）
- **194〜209小節: 4/4拍子**
- MIDIトラック終了: **260.625秒**（210小節目の開始）
- MP3の長さ: **276.936秒**（末尾約16.311秒はMIDIトラックの範囲外）

**重要:** 元の追記メモの構成見出しは、後半「141 2A'」「157 2A''」「173 2サビ」「210 アウトロ」となっていますが、MIDIではそれぞれ125、141、157、194小節目。**元のメモ見出しは変更していません**。プレーヤーの「MIDI ○○小節」表示とシーク動作のみMIDI優先です。イントロも元の見出し「002」、MIDIマーカーは第1小節です。

MIDI後のMP3末尾には小節番号を割り当てていません。これはMIDIに含まれない区間について拍子や小節が不明なためです。音声の時間シークバーから末尾まで聴くことはできます。

## 同梱ファイル

- `assets/yuseikyoku_demo_20261108.mp3`：添付されたMP3原本を同梱。ブラウザがこのファイルを直接再生します。
- `assets/yuseikyoku_20261108.mid`：添付MIDI原本。
- `assets/yuseikyoku_bar_map.json`：MIDIから算出した209小節分の開始秒と拍子・構成マーカー。
- `bar-map.js`：ブラウザで上記表を参照するためのデータ。
- `bar-player.js`：独自再生UIとシーク・小節カウンター。

## データ・通信について

- 編集内容は各ブラウザのLocalStorageに保存。FirebaseやGoogle Driveとのデータ同期はありません。
- GitHub Pagesでテストする場合、音声ファイルがアクセス可能な静的ファイルとして**一般公開**されます。非公開にしたい音源の本番運用には、別途アクセス制御が必要です。
- このテスト版ではMP3をService Workerで事前キャッシュしません。音声の範囲リクエストを妨げないため、MP3はブラウザによる通常のネットワーク取得となります。72時間キャッシュは未実装です。
- GitHub PagesではZIP内の `saiwaisan-test` **フォルダーの中身**を公開対象のルートへアップロードしてください。
- 前バージョンのPWAがキャッシュされる場合は、最新版を開き直し、必要に応じてService Workerの旧キャッシュのみ削除してください。
