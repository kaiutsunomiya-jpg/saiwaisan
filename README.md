# さいわいさん — PWA v3（4画面版）

2026年11月19日更新。ブラウザ版の「さいわいさん」を、**曲リスト／練習タイテ／セトリ作成／メトロノーム**の4画面構成にしたものです。iPhone・PC・Androidで利用でき、GitHub Pagesで無料公開できます。

メトロノームの参照元： https://kaiutsunomiya-jpg.github.io/tempo-switch-pwa/

## 主な機能

### 1. 曲リスト

- 持ち曲22曲（既存20曲＋「0時　郵政局」「さいわい免許センター改」）を一覧表示します。tuningやMC等は含まれません。
- 初期表示はCapoの小さい順。「名前順 ↑」に切り替えることもできます。
- 曲をタップすると編集できます。右上の＋で持ち曲を追加します。

| 曲名 | Capo | BPM | 演奏時間 |
|---|---:|---:|---:|
| 0時　郵政局 | 7 | 192 | 4:40 |
| さいわい免許センター改 | 4 | 88 | 4:21 |

### 2. 練習タイテ

- 初期の練習時間は120分。各項目の合計時間と残り時間を表示します。
- 「準備（20分）」「通し（30分）」「セクション（25分）」「バッファ（10分）」「休憩（10分）」「片付け（10分）」を何度でも追加できます。
- 追加した項目の時間は5〜240分の範囲で、5分刻みのプルダウンから変更できます。各項目に備考（2,000文字まで）を記入できます。
- 並べ替え、削除、名前付き保存、上書き／別名保存、読み込み、コピーに対応します。

### 3. セトリ作成

- これまでの機能を継続。持ち曲・MCなどの追加、ドラッグ並べ替え、持ち時間の計算、セットリスト保存・読み込み・削除・コピーに対応します。
- 追加された新曲2曲も選択できます。

### 4. メトロノーム【新機能】

- 元の「テンポスイッチ」の **A/B/C（初期BPM 100/120/110）** を切り替えるメトロノームをアプリ内に実装。
- −／＋または数字入力で30〜300 BPMを調整できます。
- 「＋A」「＋B」「＋C」で任意の順番に追加。ステップをタップして削除でき、「戻す」「全消去」もあります（最大256ステップ）。
- 初期シーケンス：**B→A→B→A→B→A→B→A→B→C**。
- 「再生スタート」で1ステップ目からスタート。「次のテンポへ」を押すたび、次のBPMに切り替え。末尾の次は先頭に戻ります。
- 「停止・先頭へ」「音 ON/OFF」、4拍の視覚的インジケーター、ステップ進捗表示に対応しています。
- **音色の変更・選択機能はありません。** すべての拍で共通の、約38ミリ秒の硬く短いクリック音をWeb Audioで生成します（外部音源ファイル不要、アクセントなし）。
- 他の画面に切り替えたときやアプリが非表示になったときは、安全のため再生が停止します。
- 設定したBPM・シーケンス・音ON/OFFは端末内に自動保存します。同じGitHub Pagesドメインにある元のテンポスイッチで保存した設定は、初回のみ取り込む場合があります。
- Safariなどブラウザの制約により、音を鳴らすには最初にユーザーが「再生スタート」を押す必要があります。画面ロック・バックグラウンドでの音声再生は保証されません。

## 既存のGitHub Pagesを更新する

現在の公開先： https://kaiutsunomiya-jpg.github.io/saiwaisan/

1. **更新前にバックアップを推奨**。「セトリ作成」または「練習タイテ」の右上フォルダから「バックアップ」でJSONファイルを保存します。
2. `SaiwaiSan_PWA_v3_GitHubPages.zip` を解凍します。
3. GitHubの既存 **`saiwaisan`** リポジトリを開き、Code → Add file → Upload files を選択します。
4. 解凍したフォルダの **中にある全ファイル・`assets` フォルダ**をリポジトリ直下へアップロードし、Commit changesします。**ZIPファイル自体や外側のフォルダをアップロードしないでください。**
5. `Settings → Pages` が `Deploy from a branch` ／ `main` ／ `/(root)` であることを確認。`Actions` でデプロイ完了を確認します。
6. 公開URLを再読み込みし、下部に4つのタブがあることを確認します。iPhoneのホーム画面から開く場合は、古いPWAを一度終了して開き直してください。

**注意：** GitHubの公開処理が終わっても以前の画面が残るときは、キャッシュが更新されるまでオンライン状態でSafariのURLを再読み込みしてください。ホーム画面のPWAを削除する前にJSONバックアップを取ると安心です。

## データとバックアップ

- 旧版と同じ `saiwai.pwa.state.v1` という保存キーを引き続き使うので、**同じURL・同じブラウザ保存領域**で開く限り、これまでの曲、セトリ、練習タイテなどを引き継ぎます。
- メトロノーム設定は別のローカル保存キー `saiwai.metronome.v1` を使用します。
- **v3のJSONバックアップ**には曲・セトリ・練習タイテ・メトロノーム設定を含めます。旧版のJSONバックアップも読み込めます。
- iOSではSafariとホーム画面に追加したPWAでストレージ領域が異なる場合があります。削除・機種変更前にバックアップしてください。
- 現時点でユーザーごとのログインやバンドメンバー間のリアルタイム同期は未実装です。GitHub Pagesは静的ファイルの公開先であり、保存した編集内容は各自の端末内にあります。

## 動作確認

JavaScript構文チェックを実施。ChromiumのDOMテストでは、既存3画面表示、曲数、4タブ切替、メトロノームBPM変更、11ステップへの追加・削除・取り消し・全消去・復元、再生・テンポ切替・停止・ミュート、タブ移動後の設定保持を確認しました。モバイル・PC・小画面で水平方向のはみ出しがないことも確認済みです。

音声はWeb Audioのクリック生成であり、**iPhone実機での音質と画面ロック中の挙動は未検証**です。GitHubへはまだ自動アップロードしていません。
