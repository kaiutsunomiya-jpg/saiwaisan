# さいわいさん — GitHub Pages 用 PWA

添付の `SaiwaiSan.zip`（SwiftUI / iOS）をもとに、**GitHub Pages で無料公開できるWebアプリ**として作り直したものです。画面表示名は「さいわいさん」、テーマカラーは `#3CB371`。App Store や Apple Developer Program の契約は不要です。

## 収録した主な機能

- **セットリスト**：左右独立スクロール。右の持ち曲をタップすると左のセットリストに追加（同じ曲を何度でも追加可）。左の `⠿` を指でドラッグして並べ替え、×で削除。
- **時間管理**：持ち時間を分で設定（0〜999分）、使用時間を差し引いた残り時間を表示。マイナスのときは赤で表示。
- **保存/呼び出し**：名前を付けて保存、保存済みの上書き保存、別名保存、呼び出し、削除。新規セットリスト作成時は確認画面あり。
- **コピー**：SwiftUI 版と同じ書式でコピー。MC/tuning/ミニMC/イントロ追加は曲番号に数えませんが、残り時間には加算します。
- **持ち曲**：初期20曲と4項目を同梱（SwiftUI の `SongCatalog` から抽出）。曲の追加・編集が可能。曲名、演奏時間（分/秒）、Capo 0〜10、BPM 1〜400 を入力。通常曲はCapo昇順・同じCapoでは登録順、MCなどは固定順。
- **保存済みの曲スナップショット**：持ち曲マスターを編集しても、既存セットリスト上の曲情報は自動変更しません。必要ならセットリストから一度削除して再追加。
- **文鳥**：元プロジェクトの写真を表示。
- **バックアップ**：セットリスト画面右上のフォルダーから、曲・作成中・保存済みセットリストをまとめてJSONとしてエクスポート／インポート。
- **PWA**：iPhoneのホーム画面に追加可能。初回の読み込み・キャッシュ取得後はオフライン起動に対応。

## GitHub Pages へのアップロード（前回の単語学習アプリと同じ手順）

**既存の `kotobadeck-pwa` とは別の新しいリポジトリを使ってください。**

1. GitHubにログインし、`New repository` で名前を `saiwaisan-pwa`（例）とし、**Public** で作成します。
2. このZIPをMacで解凍し、`SaiwaiSan_PWA` フォルダを開きます。
3. **フォルダ自身やZIPではなく、その中身**をリポジトリのルートにアップロードします。まだ空なら「uploading an existing file」、ファイルがある場合は `Add file` → `Upload files` です。
4. `Commit changes` を押します。
5. リポジトリの **Settings → Pages → Build and deployment** で、次のように選択します。
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/(root)`
   - `Save`
6. **Actions** タブで `pages build and deployment` が成功していることを確認します。
7. 例のリポジトリ名なら公開URLは次の形式です。

   `https://kaiutsunomiya-jpg.github.io/saiwaisan-pwa/`

   ※アカウント名やリポジトリ名を変えた場合はURLも変わります。`Settings → Pages` の「Visit site」で開けます。

**重要**：リポジトリの直下に `index.html` / `app.js` / `seed.js` / `styles.css` / `sw.js` / `manifest.webmanifest` / `assets/` が見える状態にします。`SaiwaiSan_PWA/index.html` のように一段深く入ってしまうと、通常のURLでアプリが表示されません。

## iPhoneのホーム画面に追加

1. iPhoneで公開URLを **Safari** で開きます。
2. Safariの共有メニュー → **ホーム画面に追加** → **追加**。
3. ホーム画面に現れる「さいわいさん」のアイコンで起動します。
4. 通信がある状態で一度起動し、アセットが読み込まれたあと、機内モードでも起動できるか確認してください。

## データの保存・引き継ぎについて

- 編集した持ち曲、編集中のセットリスト、保存済みのセットリスト、持ち時間は**その端末のそのWebアプリ領域**に保存されます。GitHubのファイルを書き換えません。
- **元のSwiftUIアプリにすでに保存されているデータは自動的には移行されません。** 初期24項目は一致していますが、追加・編集した分を移すにはWeb版で再入力する必要があります。
- 別端末や別のブラウザではデータは自動で同期されません。「保存済みセットリスト」→「バックアップ」からJSONを保存し、新端末で「バックアップ読込」を使ってください。
- SafariのWebサイトデータの消去、アプリ削除、端末の初期化などで、ブラウザ内に保存したデータが消える場合があります。定期的なバックアップを推奨します。
- GitHub Pagesの公開リポジトリにアップロードする**初期曲データ、ソースコード、文鳥の写真、アプリアイコンは第三者がアクセスできます。** Web版で後から入力した内容は、バックアップをアップロードしない限りGitHubには公開されません。

## ファイル構成

```
SaiwaiSan_PWA/
├── index.html               # 起動ページ・PWA設定
├── app.js                   # 全画面・セットリスト・保存・コピー・入力・バックアップ処理
├── styles.css               # iPhone用のレイアウト、ライト・ダークテーマ
├── seed.js                  # 元Swift版から取り出した初期24項目
├── sw.js                    # オフライン用Service Worker
├── manifest.webmanifest     # アプリ名、アイコン、表示方式
├── assets/
│   ├── icon-192.png
│   ├── icon-512.png
│   ├── icon-1024.png
│   └── buncho.jpg
└── README.md
```

## 更新・動作チェック

GitHubのファイルを更新した場合、オンライン状態でアプリを起動し直して最新版を読み込みます。反映されない場合はSafariでURLを開き直し、必要に応じてブラウザのキャッシュを確認してください。オフライン用のファイル一覧を大きく変更した場合は `sw.js` の `CACHE_NAME` を新しい番号に更新してください。

テスト項目：
- 起動時に20曲と4項目がある
- 右で曲をタップ→左に追加／同じ曲を2回追加／MCも追加
- 左の `⠿` で並べ替え／×で削除
- 残り時間が正しく変わる／持ち時間を変更
- コピー、名前を付けて保存、別名保存、復元、削除
- 持ち曲追加・編集と、既存セットリストにおける曲情報の保持
- 文鳥の写真
- オンライン起動後にオフライン起動
- バックアップ出力・復元

### 実装確認の範囲

元SwiftUIの初期24項目とデータ構造を照合しました。また、ChromiumのiPhoneサイズ相当の画面で、曲の追加・編集、セットリスト保存/復元/削除、マウスのPointer Eventsによるドラッグ並べ替え、ローカルデータ保存・読み込みの操作を確認しました。iPhone実機のSafariにおけるタッチ・ホーム画面・Service Worker・バックアップ操作は**未検証**です。公開後にiPhoneでご確認ください。
