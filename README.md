# さいわいさん — テスト用PWA（Firebase非接続）

## 概要

校了さんv11相当の **10画面** を持つ「さいわいさん」用試作PWAです。GitHub Pagesへ静的ファイルを設置するだけで動作します。サーバー、Firebaseプロジェクト、ログインは不要です。

- メンバー：🟢 🔵 🟠
- 9曲すべてレギュラーチューニング。曲リストはCapo昇順・演奏時間順で並べ替え可能。
- セトリ画面では隣接する同じCapoの曲を同色で表示し、Capoの切替地点で緑の濃淡を変更。
- タスク10件、予定10件、会議10件、会計10件、空き日程14日分のサンプルを登録（「（例）」付き）。練習タイテ・セトリは3スロットにサンプル登録済み。
- 「0時　郵政局」の構成11行・歌詞空欄・追記メモ10列を収録。1つ目の追記メモにGoogle Driveの音声リンクを設定。**Driveで再生**はGoogle Drive埋め込みプレーヤーを表示する方式です。Driveの共有権限・ブラウザ制限により再生できない場合は「Driveで開く」を利用してください。
- 「陥穽」の構成と歌詞10行を収録。追記メモは初期状態では0列です。
- データは端末の `localStorage` に600ms後保存（他端末には同期されません）。検索は端末内データを対象にリテラル部分一致、最大10件。

## GitHub Pagesへの公開

1. このZIPを解凍します。
2. `saiwaisan-test/` フォルダーの**中身**を、専用のGitHubリポジトリのルートにアップロードします。
3. リポジトリの **Settings → Pages** で `Deploy from a branch`、`main`、`/(root)` を指定します。
4. 公開URLをSafariで開き、共有 → ホーム画面に追加を選択するとPWAとして利用できます。

`index.html` がGitHubのリポジトリ最上位にあることを確認してください。`sw.js` と `manifest.webmanifest` も同じ場所に必要です。

## 編集内容・サンプルのリセット

- このアプリの編集内容は**その端末・そのURL・そのブラウザ内だけ**に保存されます。
- 別のスマホやPCで開いた場合は別のサンプル状態から始まり、変更は同期されません。
- 検索画面右上のデータ管理アイコンから **JSONバックアップ / JSONの復元 / サンプルに戻す** を選択できます。
- `seed-data.json` がサンプルデータの原本です。起動時には `seed-data.js` を読み込むため、手動でサンプル原本を変更する場合は両方を更新してください。
- オフラインで開くには、公開URLをオンラインで一度正常に開き、PWAのアセットをキャッシュしてから利用してください。Google Driveの音声プレビューは通信を必要とします。

## セキュリティ・利用上の注意

本テスト版には**認証・権限管理・Firebaseへの接続・共有同期がありません**。公開リポジトリやGitHub Pagesに置くと、`seed-data.js`、`seed-data.json` に含まれる曲詳細コメント・歌詞・Drive URLが第三者から閲覧できる可能性があります。公開前に内容とDriveの共有範囲を確認してください。実運用でメンバーのみ閲覧させるには、認証・アクセス制御付きの本番構成を別途導入する必要があります。
